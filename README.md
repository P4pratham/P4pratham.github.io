## 🎨 Customization

To customize this portfolio for your use:

1. **Update Personal Information**:
   - Edit `index.html` to update name, title, experience details
   - Update contact information and social media links

2. **Modify Colors**:
   - Edit CSS variables in `styles.css` under `:root`
   - Primary color, secondary color, and gradients can be customized

3. **Add Projects**:
   - Update the projects section in `index.html`
   - Add your own project descriptions and technologies

4. **Update Skills**:
   - Modify skill cards in the skills section
   - Adjust progress bars percentages

## 🚀 Deployment to GitHub Pages

### Step 1: Create a GitHub Repository

```bash
# Initialize git (if not already done)
git init

# Add all files
git add .

# Commit changes
git commit -m "Initial commit: Portfolio website"

# Add remote repository
git remote add origin https://github.com/YOUR-USERNAME/YOUR-USERNAME.github.io.git

# Push to GitHub
git push -u origin master
```

### Step 2: Enable GitHub Pages

1. Go to your repository on GitHub
2. Click on **Settings**
3. Scroll to **Pages** section
4. Under **Source**, select `master` branch
5. Click **Save**
6. Your site will be published at `https://YOUR-USERNAME.github.io`

### Alternative: Using a Custom Repository Name

If you want to use a custom repository name (not username.github.io):

1. Create a repository with any name (e.g., `portfolio`)
2. In GitHub Pages settings, select the branch to deploy
3. Your site will be at `https://YOUR-USERNAME.github.io/REPO-NAME`

## 🔧 Local Development

To run locally:

1. Clone the repository
2. Open `index.html` in your browser
3. Or use a local server:

```bash
# Using Python
python -m http.server 8000

# Using Node.js
npx http-server
```

Then visit `http://localhost:8000`
